# Kodi grouplist behavior

A bounded grouplist provides native scrolling, `scrolltime`, and focus/default-control
behavior. It is the private Home screen’s sole vertical mover; row geometry remains
fixed and the viewport clips previews.

Source: <https://kodi.wiki/view/Group_List_Control>
Refresh when changing Kodi generation or replacing the container type.

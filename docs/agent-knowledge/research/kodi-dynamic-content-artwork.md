# Dynamic content and artwork

Plugin add-ons supply dynamic list items; the skin still owns geometry, clipping,
loading/empty presentation, and artwork controls. Texture loading can delay visible
motion, so Starlane caps preload at two, background-loads dynamic art, and defers large
hero changes until focus settles.

Sources: <https://kodi.wiki/view/Dynamic_List_Content> and
<https://kodi.wiki/view/Skinning_Engine>. Refresh for Kodi engine changes.

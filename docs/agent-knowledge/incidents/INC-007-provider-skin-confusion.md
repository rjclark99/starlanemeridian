# Provider errors mistaken for skin errors

## Summary

Umbrella Trakt HTTP errors and Mad Titan failures appeared beside widget symptoms,
leading to speculative geometry/provider changes.

## Diagnose and prevent

Run identical navigation with a bounded static/local fixture. Separate directory
completion, route validity, artwork loading, focus, geometry, animation, and hero
state. Do not upgrade providers during visual remediation.

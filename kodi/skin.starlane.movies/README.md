# Starlane Movies experimental skin

Experimental Kodi Omega skin used for Starlane Movies design and hardware testing.

The skin retains required upstream helper dependencies and internal compatibility
identifiers. Its visible identity, palette, startup, backgrounds, icon, and user-facing
copy are Starlane Movies. It is not part of the signed production release manifest.

This source was derived from
[Titan BINGIE MOD](https://github.com/AchillesPunks/skin.titan.bingie.mod/) under
GPL-2.0. Original contributor, source, and licence information remains in `LICENSE`
and the add-on metadata.
